# Inventário de componentes

`componentes.tsv` registra origem, destino, commit exato e resultado da coleta.

Política:
1. Licenças e avisos de copyright dos doadores devem permanecer preservados.
2. `almoxarifado/` é somente origem técnica; alterações entram em `oficina/`.
3. Nenhuma credencial real pode ser armazenada neste repositório.
4. APIs oficiais de Meta e TikTok são a autoridade de contrato quando divergirem de MCPs comunitários.
5. Um componente só passa do almoxarifado para a oficina depois de validação de licença, segurança, contrato e testes.
